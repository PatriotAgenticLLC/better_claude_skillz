# writing-style banned list (FAIL tier)
# Derived by hand from SKILL.md in this folder, which is the source. Edit SKILL.md first,
# then this file; tests/test_banned_list.py fails if the two drift apart.
# This is the list code should fail on. Words banned only in one sense are in
# review.txt (flag for a human); Tier 2 (warn) is in avoid-clustering.txt.
#
# Format: one lowercase term or phrase per line; lines starting with # are comments.
# Matching rules for a checker (tests/test_banned_list.py `matches` is the reference):
# - Case-insensitive. Normalize curly apostrophes to straight ones first (’ to ').
# - Put a word boundary only where the term starts or ends with a letter or digit.
#   Phrases ending in punctuation ("certainly!") get no trailing boundary, so
#   "Certainly! Here it is." matches.
# - Single words are base forms; also match these inflections: +s, +es, +d, +ed, +ing,
#   e-drop +ing (leverage to leveraging), and y to ies (synergy to synergies). So
#   unleash also matches unleashes. tests/test_banned_list.py `forms` is the reference.
# - Hyphenated terms should also match with a space (game-changer, game changer).
# - Openers ("in today's fast-paced", "in a world where", "continues to evolve") and
#   closers ("in conclusion", "in summary", "in essence") are banned at the start or end
#   of a section; matching them anywhere is an acceptable approximation.
# - "of course!", "certainly!", "absolutely!" are the chatbot interjection form only;
#   "of course" inside a normal sentence is fine, which the ! enforces.
# - The PatriotAgentic Brand Book (pa-aic docs/brand/PatriotAgentic-Brand-Book.md)
#   governs brand terms. Its banned words are all here. Its Retired terms list is not
#   copied; a brand checker should read it from the Book.
